Foodies — REST API Endpoints

Web Programming 1 · Final version · Julien Matar, Peter Nehmeh, Freddy Rayess

Base URL: http://localhost:4040/api (online: https://<our-app>/api) · All requests and responses are JSON. The website in view/ is served at the same address.

Status codes: 200 OK, 201 Created, 204 Deleted, 400 invalid input, 401 not logged in, 403 not allowed, 404 not found, 409 conflict (already exists), 413 body too large, 429 too many requests, 503 feature not set up, 500 server error. Errors are always { "error": "message" }.

Access: Public = no login · User = logged in (JWT in the httpOnly cookie token) · Owner = the user who wrote the review · Admin = admin role (checked again in the database).

Rate limits per visitor: all /api 600 / 15 min · register + login 10 / 15 min · chat 6 / min, and at most CHAT_DAILY_LIMIT (300) AI answers a day for the whole site.

Sort values for /restaurants?sort=: authentic, mix (fusion first), modern, price_asc, price_desc, top_rated, nearest (needs near). Styles: heritage, authentic, fusion, modern. Allergens: gluten, dairy, nuts, sesame, fish, eggs. Meat: none, lamb, beef, chicken, fish.
